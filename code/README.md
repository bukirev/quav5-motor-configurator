# Код проекта QUAV V5+ (ArduCopter 4.7.2 / PX4)

## Конфигуратор маппинга моторов (2026-11-20)

Главный новый инструмент проекта: настраивает соответствие логических моторов
ArduPilot (M1…M8) физическим выходам `MAIN Mx` и проверяет направление вращения
коаксиальных пар.

| Файл | Назначение |
|---|---|
| `motor_configurator.py` | GUI (Tkinter): подключение по COM, чтение параметров, запрос версии прошивки, идентификация моторов тестом (кнопки A…H), чек-лист проверки вращения X/8, план правки, применение с бэкапом и readback, запись `FRAME_*` с перезагрузкой и сверкой, экспорт `.params` и отчёта |
| `motor_mapping_core.py` | чистая логика без GUI и MAVLink: модель рамы (§5.8), ярусы и буквы кнопок, сопоставление наблюдений с моторами, диагностика назначений функций 33…40, сборка плана |
| `ardupilot_frames.py` | таблицы рамы, сгенерированы из `AP_MotorsMatrix.cpp` ArduPilot 4.7.2; вручную не редактировать |
| `mavlink_ardupilot.py` | MAVLink-канал: heartbeat, параметры (чтение/запись), тест мотора, запрос версии прошивки (CMD 520), перезагрузка (CMD 246), телеметрия |
| `run_tests.py` | запуск всех наборов тестов |

Запуск: `python motor_configurator.py`. Нужен Python 3.9+ и `pyserial`
(`python -m pip install pyserial`). `pymavlink` не требуется.

Тесты: `python run_tests.py`
(`test_motor_mapping_core.py`, `test_mavlink_codec.py`, `test_motor_configurator_gui.py`).

**Осторожно:** приложение умеет физически крутить моторы (`MAV_CMD_DO_MOTOR_TEST`)
и записывать параметры (`PARAM_SET`). Пропеллеры должны быть сняты, аппарат —
на земле, safety switch — в Safe, RC откалиброван, плата disarm. Тест запускается
только по кнопке и только после подтверждения «пропеллеры сняты»; при состоянии
ARMED тест блокируется (проверка идёт по снимку состояния до старта — сам тест
поднимает ARMED на плате); перед записью приложение показывает, что именно
изменится, и спрашивает подтверждение; перед записью делается полный бэкап
параметров в `configs/`.

Запись `FRAME_CLASS`/`FRAME_TYPE` — отдельное действие: после неё приложение
останавливает тест мотора, дожидается disarm, перезагружает плату (CMD 246),
ждёт heartbeat и повторно читает параметры для сверки.

Стандарты и обоснование: `../docs/MOTOR_MAPPING_ARDUPILOT_4.7.2.md`.

## Скрипты чтения (для PX4, сессия 2026-10-26)

- `mavlink_read_params.py` — read-only подключение по serial/MAVLink: ждёт heartbeat, показывает SYS_STATUS и GPS_RAW, запрашивает выбранные параметры через `PARAM_REQUEST_READ`. Не отправляет `PARAM_SET`, arm/disarm или actuator/motor commands.
- Нужен Python и пакет `pyserial`. Пример: `python mavlink_read_params.py --port COM18 --baud 115200`.
- `download_px4_params.py` — полный список параметров PX4 только чтением, сохраняет `.params` в `configs/`.
  Последняя выгрузка: `../configs/px4_params_COM18_20261026-172517.params` — 1153/1153 параметра основного компонента PX4.
  Расшифровка: `../docs/CONFIGURATION_GUIDE_2026-10-26.md`. В выгрузке нет параметров отдельных CAN-компонентов.
  Снимок не отправляли обратно в контроллер; не восстанавливай его без проверки точной платы и версии PX4.

## Что использовалось в сессии 2026-10-26

Первоначальные запросы к контроллеру выполнялись короткими Python-фрагментами, переданными через PowerShell прямо в `python -`; исходники тех фрагментов отдельными файлами не сохранялись. Для чтения использовался serial/MAVLink, heartbeat, `PARAM_REQUEST_LIST` / `PARAM_REQUEST_READ` и разбор `PARAM_VALUE`/телеметрии. Для изменения MAIN-функций и таймеров отправлялись `PARAM_SET`; для перезагрузки — MAVLink reboot command; для кратких тестов — `MAV_CMD_ACTUATOR_TEST` с последующей остановкой выходов.

Точный исходный Python-код actuator test не был сохранён, поэтому не называйте read-only скрипт точной копией того тестового кода. Его результат, значения и ограничения описаны в `../logs/2026-10-26-no-motor-output.md` и `../docs/WORKFLOW_AND_AGENT_GUIDE.md`.

**Осторожно:** тестовый actuator-код способен физически запустить ESC/моторы. Не запускать без снятых пропеллеров, проверки disarmed/heartbeat, короткого теста по одному выходу и прямой просьбы пользователя. Read-only скрипт безопасен относительно выходов, но занимает COM-порт на время чтения.
