# Журнал работ

Создавайте отдельный файл на каждую сессию, например `2026-10-26-setup.md`.

Рекомендуемые поля:

- дата и участники;
- плата и версия PX4/QGroundControl;
- питание и способ подключения;
- цель сессии;
- исходные значения/состояние;
- выполненные действия и изменения (`было → стало`);
- результат и способ проверки;
- открытые вопросы и следующий безопасный шаг.

Не записывайте секреты. Сырые логи устройства храните только если они нужны для диагностики; указывайте источник и не редактируйте оригинал.
