# QUAV V5+ (PX4 / ArduCopter)

Изолированное рабочее пространство для настройки полётного контроллера, который пользователь называет QUAV/CUAV V5+.

## Текущее состояние — 2026-11-20

- Плата: **CUAV V5+**, прошивка **ArduCopter V4.7.2** (commit `fb773567`), подтверждено по файлам в `C:\Trading\!!!\QUAV5+\CUAVv5`.
- На 26.10.2026 на плате стоял **PX4** (см. раздел ниже): плату перепрошили в ArduPilot, поэтому настройки PX4 больше не актуальны.
- Рама: 8 моторов, 4 луча в компоновке квадро-X, по 2 мотора на луч, пара на луче вращается встречно (верхний передний правый — против часовой, нижний передний правый — по часовой).
- Целевая конфигурация рамы в ArduPilot: `FRAME_CLASS=4` (OCTAQUAD), `FRAME_TYPE=1` (X); назначение `SERVOx_FUNCTION` и направление вращения определяются измерением.

Создан **конфигуратор маппинга моторов**: [`code/motor_configurator.py`](code/motor_configurator.py) — GUI, который подключается по COM-порту, читает параметры, запрашивает версию прошивки, гоняет тест мотора кнопками A…H, по вашим отметкам строит правильный план `SERVOx_FUNCTION`/`SERVOx_REVERSED`, проверяет коаксиальные пары и назначения функций 33…40, и применяет план с бэкапом и readback. Запись `FRAME_CLASS`/`FRAME_TYPE` — отдельным действием: с перезагрузкой платы и повторной сверкой значений.

Исследование стандартов маппинга ArduPilot 4.7.2 со ссылками на исходники: [docs/MOTOR_MAPPING_ARDUPILOT_4.7.2.md](docs/MOTOR_MAPPING_ARDUPILOT_4.7.2.md). Хронология работы: [logs/2026-11-20-motor-configurator.md](logs/2026-11-20-motor-configurator.md) и [logs/2026-11-20-spec-verification-wave2.md](logs/2026-11-20-spec-verification-wave2.md) (вторая волна проверки спецификации).

## Последняя проверенная конфигурация PX4 — 2026-10-26 (устарело: плата перепрошита)

- Через COM18 получен MAVLink heartbeat: PX4, system 1/component 1, тип Octocopter. Точная маркировка платы и версия/build PX4 пока неизвестны.
- По запросу пользователя скачаны 1153/1153 параметра основного компонента PX4. Выгрузка read-only: параметры и моторы не изменялись.
- В PX4 назначены MAIN1–8 → Motor 1–8 и частота MAIN 50 Гц; физический сигнал на разъёмах не подтверждён измерительным прибором.
- DroneCAN включён; внешний CAN-магнитометр обнаружен. GPS по CAN в последней проверенной телеметрии не обнаружен.
- Пользователь сообщил: восемь моторов, по два на четырёх лучах; пропеллеры сняты.

Подробности и приоритетные проверки: [гайд по конфигурации](docs/CONFIGURATION_GUIDE_2026-10-26.md), [исходный снимок параметров](configs/px4_params_COM18_20261026-172517.params), [порядок диагностики и памятка агенту](docs/WORKFLOW_AND_AGENT_GUIDE.md).

## Каталоги

- [`docs/`](docs/README.md) — подробные инструкции и проверенные сведения.
- [`code/`](code/README.md) — конфигуратор моторов, скрипты чтения/выгрузки и описание предыдущих действий.
- [`configs/`](configs/) — исходные snapshots параметров.
- [`logs/`](logs/) — датированная хронология работ и результатов.
- [`research/`](research/) — выдержки из исходников ArduPilot 4.7.2, использованные при сверке
  маппинга, плюс скриншоты GUI. Атрибуция и лицензии — в [`research/NOTICE.md`](research/NOTICE.md).

Перед действиями с реальным аппаратом прочитайте [правила агента](AGENTS.md). Для actuator-тестов пропеллеры должны быть сняты; сначала проверьте heartbeat и disarmed state.

## Запуск

```powershell
# все наборы проверок (3 набора, офлайн, без GUI-окна)
python code/run_tests.py

# GUI собирается без ошибок (окно не показывается)
python code/motor_configurator.py --selftest

# сверка вендоренных файлов ArduPilot с upstream (нужна сеть)
python code/verify_vendored_sources.py
```

Требуется Python 3.11+ и `pyserial` (нужен только для работы с реальной платой;
тесты идут без него).

## Публикация на GitHub

Публичный репозиторий: **[bukirev/quav5-motor-configurator](https://github.com/bukirev/quav5-motor-configurator)**.

Что публикуется: приложение (`code/`), документация (`docs/`), хронология работ (`logs/`),

эталон `pymavlink`/`common.xml`, дубликат `research/ardupilot_tag/` и архив `!!!px4.zip`
(его содержимое побайтово продублировано в `code/`, `docs/`, `logs/`). Перечень — в
[`.gitignore`](.gitignore) и в `research/NOTICE.md`.
