# Отчёт настройки CUAV/QUAV V5+ с PX4 — 2026-10-26

## Краткий итог

Контроллер подключался к компьютеру через `COM18`. По запросу пользователя выполнены чтение параметров, назначение восьми выходов MAIN, изменение частоты MAIN на 50 Гц с перезагрузкой и краткий последовательный тест моторных функций. Пропеллеры были сняты; состояние контроллера проверялось как disarmed.

## Аппарат и исходная конфигурация

- Плата: пользователь назвал её QUAV V5+; фактическая маркировка на корпусе отдельно не фотографировалась.
- Прошивка: PX4. Точная версия/build number не считаны.
- MAVLink heartbeat сообщил тип аппарата Octocopter и PX4 Autopilot.
- Подключение: USB/последовательный порт `COM18`.
- Конструкция по словам пользователя: 8 моторов, по два на каждом из четырёх лучей; пропеллеры сняты.
- До правок: `SYS_AUTOSTART=12001` (Generic 10-inch Octo Coaxial), `CA_AIRFRAME=0` (Multirotor), `CA_ROTOR_COUNT=8`, `SYS_AUTOCONFIG=0`.
- Параметры геометрии роторов указывали четыре парных верхних/нижних позиции; существующий профиль совпадал с описанной коаксиальной схемой. Профиль рамы не менялся.

## Найденная причина отсутствия сигнала

До назначения выходов были считаны:

- `PWM_MAIN_FUNC1` … `PWM_MAIN_FUNC8` = `0` (Disabled);
- все прочитанные `PWM_AUX_FUNC` также были `0`;
- `PWM_MAIN_DIS1` … `PWM_MAIN_DIS8` = `1000`;
- `PWM_MAIN_MIN1` … `PWM_MAIN_MIN8` = `1100`;
- `PWM_MAIN_MAX1` … `PWM_MAIN_MAX8` = `1900`.

MAIN1–8 не имели назначенных функций моторов, поэтому PX4 не выдавал на них соответствующие команды моторам.

## Изменения выходов

Через MAVLink `PARAM_SET` назначены и повторно считаны:

| Параметр | Назначение | Значение |
|---|---|---:|
| `PWM_MAIN_FUNC1` | Motor 1 | 101 |
| `PWM_MAIN_FUNC2` | Motor 2 | 102 |
| `PWM_MAIN_FUNC3` | Motor 3 | 103 |
| `PWM_MAIN_FUNC4` | Motor 4 | 104 |
| `PWM_MAIN_FUNC5` | Motor 5 | 105 |
| `PWM_MAIN_FUNC6` | Motor 6 | 106 |
| `PWM_MAIN_FUNC7` | Motor 7 | 107 |
| `PWM_MAIN_FUNC8` | Motor 8 | 108 |

После назначения `SERVO_OUTPUT_RAW` показывал восемь значений `1000` в состоянии disarmed. Это телеметрические значения PX4, а не осциллографическое подтверждение сигнала на контактах.

## Частота PWM MAIN

Изначально три группы MAIN работали на 400 Гц. По просьбе пользователя установлено 50 Гц во всех группах:

| Параметр | Каналы | До | После |
|---|---|---:|---:|
| `PWM_MAIN_TIM0` | MAIN1–2 | 400 Гц | 50 Гц |
| `PWM_MAIN_TIM1` | MAIN3–4 | 400 Гц | 50 Гц |
| `PWM_MAIN_TIM2` | MAIN5–8 | 400 Гц | 50 Гц |

PX4 помечает эти параметры как требующие перезагрузки. До перезапуска heartbeat показывал disarmed; после отправки `MAV_CMD_PREFLIGHT_REBOOT_SHUTDOWN` контроллер снова появился на `COM18`, оставался disarmed, а повторное чтение подтвердило `50/50/50`.

При 50 Гц период PWM составляет 20 мс. Совместимость частоты 50 Гц с конкретными ESC нужно сверить с их документацией.

## Тест 1200 мкс

По просьбе пользователя выполнен краткий последовательный тест Motor 1–8 при снятых пропеллерах:

- для каждого мотора отправлялось 10 обновлений `MAV_CMD_ACTUATOR_TEST` с таймаутом 1 с;
- тестовое нормализованное значение было `0.125`. При текущем диапазоне `PWM_MAIN_MIN=1100` и `PWM_MAIN_MAX=1900` это рассчитано как 1200 мкс;
- после каждого мотора отправлялась команда остановки; все моторы тестировались по одному, контроллер не армировался.

После завершения heartbeat оставался disarmed, а `SERVO_OUTPUT_RAW` снова показывал `1000` на всех восьми каналах. Во время теста форма сигнала на физических контактах M1–M8 осциллографом/логическим анализатором не измерялась. Поэтому факт выдачи именно 1200 мкс на контактах и реакция ESC физически не подтверждены. Пользователь не сообщал, изменились ли звуковые сигналы ESC или вращались ли моторы.

## Что проверить дальше

1. Снять осциллограмму между Signal и GND на одном из `M1–M8` во время теста: ожидаемый PWM — импульсы около 1200 мкс с периодом 20 мс.
2. Если импульсов нет, проверить ориентацию трёхконтактного кабеля и общий GND, затем состояние IO/питания по руководству CUAV V5+.
3. Уточнить модель ESC и поддерживаемый протокол. MAIN на V5+ — IO-выходы; если ESC требуют DShot, проверить совместимость и выбрать поддерживаемый тракт вывода до дальнейших тестов.
4. После подтверждения сигналов проверить соответствие Motor 1–8 физическим позициям и направления вращения — только с пропеллерами снятыми.
